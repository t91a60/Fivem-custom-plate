# Artwork

Place your own PNG, JPG, JPEG or WebP files here. For example, use `Config.DiffuseImageUrl = 'assets/plate.png'` after adding that image. No `plate.png` is included.

Use lowercase extensions and paths without spaces. Subdirectories are supported. Keep a backup before changing existing artwork. Check the rights and license terms of any images you distribute; the project's MIT license applies to its code and documentation.
